# Football fixtures and results lookup

Added 2026-10-28 using existing keyless MCP tools. Try “แมนยูแข่งวันไหน”, “ตารางแข่งน่อล”, “โปรแกรมแมนซิตี้” or a team/date/category-specific result question. Room web mode, tool roles, query confirmation, fresh access checks and normal quotas still apply.

Fixture/result/standings questions with football or recognized team cues now enter lookup without requiring “latest”. Thai/English aliases cover Manchester United, Manchester City, Arsenal and Fleetwood Town; other names are preserved. Search hints prioritize matching club sites, Premier League, LiveScore, Flashscore and Sofascore when they fit the existing 400-character query bound. Results are ranked by exact public host, not an assertion of accuracy. At most two tools: search plus one selected page. PL/United/score sites use the existing read-only Playwright reader; City/Arsenal/Fleetwood use text reading. Direct URLs retain their existing route. No new API/dependency/service or continuous polling.

The synthesis instructions distinguish scheduled/live/full-time/postponed/cancelled states and require evidenced competition, date, teams and score. Preserve requested men/women/youth category. Convert kickoff to configured TIMEZONE (default Asia/Bangkok) only with an explicit source timezone/offset; otherwise disclose unknown timezone. Search snippets are explicitly marked and cannot certify a live score. Generic menus, Loading and challenge pages are not match evidence. Incomplete/conflicting/undated information must be acknowledged. No login, CAPTCHA bypass, hidden sports endpoint or invented result.

Sources stay hidden until requested using the existing four controls or a source follow-up. A lookup is one snapshot, never a subscribed real-time feed. External accessibility varies. Fleetwood domain hints are supported, but its fixture page was not directly verified readable. See Thai guide for official/public source links and rollout records for actual probe limits.
