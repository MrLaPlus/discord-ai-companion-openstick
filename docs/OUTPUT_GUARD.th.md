# การแก้ข้อความวิเคราะห์หลุดและคำถามผลบอล

2026-10-28 — ดูผลเปิดใช้ล่าสุดใน [PROGRESS.md](../PROGRESS.md)

ผู้ใช้รายงานว่าคำถามสะกดคลาดเคลื่อนเกี่ยวกับสกอร์บอลแมนยูล่าสุดได้รับข้อความ `[Thinking Process]` และการวิเคราะห์ประวัติอนิเมะ แทนคำตอบสั้น ๆ บอทยังไม่มี MCP/แหล่งผลบอลสดเชื่อมอยู่ในรุ่นนี้

## สิ่งที่แก้

- ขอ Groq ด้วย `reasoning_effort=none` และ `reasoning_format=hidden` เพื่อให้ได้เฉพาะคำตอบสุดท้าย ไม่ส่ง `include_reasoning` ร่วมกับ `reasoning_format` ตาม [เอกสาร Groq](https://console.groq.com/docs/reasoning)
- ตรวจรูปแบบขาเข้าที่ adapter และซ้ำที่ renderer ก่อนแบ่งส่ง: แยกข้อความ final ที่มีขอบเขตชัดเจนจาก reasoning tags/headers ที่รู้จัก หากมีแต่ข้อความวิเคราะห์ แท็กไม่ครบ หรือแท็กซ้อน ให้ตอบข้อความสถานะคงที่โดยไม่ส่ง trace
- แยก field `message.reasoning` ออกจาก `message.content` ตามเดิม ไม่อ่าน field reasoning มาเป็นคำตอบ และยังนับการใช้โควตาของคำตอบที่ถูกปฏิเสธ
- คำตอบที่อ่านได้แต่จบเพราะ `finish_reason=length` ยังแบ่งส่งครบเท่าที่โมเดลสร้าง พร้อมข้อความว่าคำตอบอาจไม่ครบและให้พิมพ์ “ต่อ” ไม่ส่ง thinking-only completion เพื่ออ้างว่าได้คำตอบแล้ว
- ย้ำใน prompt ว่าตอบเฉพาะผู้ใช้ ไม่ทวนกระบวนการคิด/reference JSON และให้คำถามล่าสุดสำคัญกว่าหัวข้อเก่าที่ไม่เกี่ยวข้อง
- ย้ำว่าห้ามด่าหรือกล่าวหาผู้ใช้ว่าแกล้งถามเรื่องความสามารถ และบล็อกถ้อยคำโจมตีตรง ๆ ที่ผู้ใช้รายงานในขอบเขตขาออก มุก/คำสบถทั่วไปที่ไม่โจมตีคนยังใช้ได้ตามค่า tone
- ดักคำถามผลบอลสดที่ชัด รวมกรณีสะกดคลาดเคลื่อนที่รายงาน ก่อนดึงประวัติ/เรียก AI: บอกตรง ๆ ว่ายังเช็กสกอร์สดไม่ได้ ไม่เดาสกอร์หรือย้ายไปคุยอนิเมะ คำถามว่าคนในห้องพูดเรื่องผลบอลว่าอะไรยังใช้ทางค้นประวัติเดิม

## ขอบเขต

ตัวกรองเป็นกฎสำหรับรูปแบบที่รู้จัก ไม่ใช่ตัวจำแนกข้อความคิดภายในทุกรูปแบบที่เป็นไปได้ แท็ก reasoning ที่ปรากฏเป็นข้อความจริงในคำตอบทางเทคนิคอาจทำให้ตอบสถานะปลอดภัยแทน การตอบไทย/emoji/โค้ดปกติและการแบ่งส่งต้องผ่าน regression เดิม

ไม่มีการติดตั้ง MCP เพิ่ม เปลี่ยนโมเดล เพิ่ม dependency หรือเปลี่ยน schema ในงานแก้นี้ เมื่อทำ MCP จริงต้องเปลี่ยนทางตอบว่าไม่มีผลบอลสดไปใช้ capability ที่ตรวจว่าค้นได้จริงก่อน ไม่ลบ guard โดยสมมติว่ารายการ server แปลว่าพร้อมค้นแล้ว

การทำซ้ำใช้ข้อมูลจำลอง ไม่บันทึกข้อความวิเคราะห์หรือ ID จริงที่ผู้ใช้ส่งมาลง Git ไม่ได้เก็บ wire response เดิม จึงไม่อ้างว่า replay การสุ่มคำตอบนั้นหรือทราบ finish reason ของเหตุการณ์เดิม
