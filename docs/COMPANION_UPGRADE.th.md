## หน้าควบคุม

เปิด `/panel` ข้อความตั้งค่าเห็นเฉพาะคุณ ปุ่มมีอายุ5นาที ตรวจสมาชิก บทบาท เจ้าของเซิร์ฟเวอร์และสิทธิ์ดูห้องใหม่ทุกครั้ง ผู้ใช้ทั่วไปตั้งโทน/ความยาวของตัวเอง เปิดกลับการแซว ปิดเก็บข้อมูลและยืนยันลบได้ แอดมิน Manage Server เปิดหน้าห้อง เครื่องมือ ข่าว โควตา สถานะและหยุดฉุกเฉินได้ เปลี่ยนค่าแล้วเปิด /panel ใหม่ ปุ่มเก่าถูกยกเลิกเมื่อบริบท/สิทธิ์เปลี่ยน

- ห้อง: เปิดตอบ ห้องบอท เพดานโทน0–4 พักห้อง; ไม่เปิดอ่านหรือแชร์ประวัติอัตโนมัติ
- แทรกคุย: ปิด0, นานๆที0.05, ปกติ0.1; ช่วงพักอย่างน้อย300วินาทีและเพดานเริ่มต้น3ครั้ง/ชั่วโมง ตั้งช่วงเงียบได้ ยังปิดจนแอดมินเลือกเปิด ห้องบอทคงตอบปกติเมื่อไม่แท็ก
- เครื่องมือ: เลือกหนึ่งในหกเครื่องมือ เปิด/ปิดและตั้ง role IDs อนุญาต/ปฏิเสธ (comma ไม่เกิน20) ปฏิเสธมีผลเหนืออนุญาต รายการอนุญาตว่าง=ทุกบทบาทที่มีสิทธิ์พื้นฐาน; ไม่มีสิทธิ์ข้าม ACL Discord ไม่ยกเว้น admin จากนโยบายเครื่องมือ
- โหมดค้นเว็บ: off/button/auto/hybrid แบบเดิม
- ข่าว: หัวข้อสาธารณะ/คำที่ไม่ต้องการไม่เกิน10คำ และ RSS/Atom HTTPSประจำห้อง1URL (ว่างใช้ default feeds) หัวข้อใช้เสริมคำถามข่าวทั่วไป คำยกเว้นกรองข้อความ feed; ไม่ส่งข่าวอัตโนมัติ ไม่ได้เพิ่ม scheduled notifications

## สนทนา

ความยาว auto ตอบคุยเล่น1–3ประโยคและขยายเมื่อคำถามซับซ้อน ผู้ใช้ตั้ง short/detailed หรือพิมพ์ “สั้นๆ/ละเอียด” เพื่อกำหนดครั้งนั้น เป็นคำสั่งกำกับโมเดล ไม่ตัดคำตอบที่มีสาระทิ้ง ยังแบ่งข้อความยาวตามเดิม

เมื่อเรียกบอทตรงๆว่า “พอ/พอแล้ว/หยุดแซว/ไม่เล่น/จริงจัง” ลดโทนส่วนตัวชั่วคราว30นาที และสุภาพเมื่อเนื้อหาจริงจัง กลับผ่าน /panel→กลับมาแซวได้ ไม่เปลี่ยนโหมดถาวร0–4

แทรกคุยใช้กิจกรรม Gateway ใน RAM ไม่เกิน6ข้อความ/ห้อง100ห้อง อายุ30วินาที ต้องมีอย่างน้อย3ข้อความจาก2คน ไม่เลือกฉากที่มีสัญญาณความทุกข์ ผู้ปิดเก็บข้อมูลไม่ถูกใส่ในฉาก ไม่เพิ่มการเก็บประวัติห้องใหม่ จังหวะ/ความเหมาะสมเป็น heuristic ไม่รับรองเข้าใจอารมณ์ทุกกรณี

`/joke propose text:... subject:...` เสนอมุกสั้น240ตัวอักษร (ไม่เลือกsubject=ตัวเอง) เจ้าตัวต้องยินยอมและแอดมินอนุมัติผ่านปุ่ม5นาที เสนอแซวตัวเองถือว่ายินยอมแล้ว เก็บได้20มุก/ห้อง อายุ30วัน `/joke list` ดูรหัส; `/joke remove joke_id:...` ผู้เสนอ เจ้าตัว หรือแอดมินลบได้ ห้ามแท็กคนอื่นหลายคน/บทบาท/ทั้งห้อง ตัวกรองตรวจ mentions ไม่ได้เข้าใจชื่อคนทุกชื่อ แอดมินยังต้องพิจารณาเนื้อหา

มุกเป็นตัวเลือกประกอบเมื่อคุยกับเจ้าตัวและโทนมากกว่า0 ไม่ใช่ข้อเท็จจริงส่วนตัว ไม่ใช้ทุกคำตอบ เมื่อใครที่เกี่ยวข้องปิดความจำ/ลบข้อมูล มุกถูกตัดออกจากบริบทและการกู้คืนด้วย

## ค้นและค้นต่อ

คำค้นกำกวมเช่น “ค้นเรื่องแมว” ให้เลือกเว็บ/ประวัติ/ทั้งคู่ ปุ่มและคำตอบจากปุ่มเห็นเฉพาะผู้ถามและหมดอายุ5นาที “ทั้งคู่” ให้ตรวจคำค้นสาธารณะใน modal ก่อน แชทที่ค้นมาไม่ถูกป้อนให้ตัววางแผนเว็บ ค้นประวัติด้วยสิทธิ์ของผู้ถามแบบ /ask ไม่เปิดแชร์เพิ่ม

- หาเพิ่ม: ประวัติใช้ cursorเดิม เว็บเปลี่ยนคำค้นต่อและตัด URLที่อ่านแล้วใน RAM30นาที/200ขอบเขต ผลเว็บเป็นการค้นต่อแบบ best effort ไม่ใช่ cursorของผู้ให้บริการ อาจไม่พบแหล่งใหม่และจะบอกตรงๆ
- เจาะเรื่องนี้: เปิดคำค้นเดิมให้ปรับเป็นหัวข้อย่อยก่อนค้นเว็บ; คำถามที่อาจอ้างถึงข้อมูลส่วนตัวเริ่มช่องคำค้นว่าง
- ดูที่มา: ใช้แหล่งของคำตอบในขอบเขตผู้ถาม ไม่เรียก AI เพิ่ม ประวัติยังตรวจสิทธิ์/ต้นทางใหม่ ที่มาปกติซ่อนเหมือนเดิม
- เทียบได้ไม่เกิน3ลิงก์ HTTPS ต่อคำถาม ใช้อ่านข้อความธรรมดาหนึ่งครั้งต่อลิงก์ ไม่มี browser fallback เพิ่มในคำถามเปรียบเทียบ ใช้โควตาMCPร่วมกันและเวลางาน90วินาที แหล่งอ่านไม่ได้ต้องบอกว่าเทียบไม่ครบ บริบทมีขีดจำกัดจึงไม่รับรองอ่านครบทุกหน้า

## งบและสถานะ

โควตาAIเดิมยังอยู่ เพิ่มหมวดchat/planner และจำนวนcallsรายเครื่องมือใน24ชั่วโมงย้อนหลัง ไม่มีหมวดภาพ/เสียงที่ใช้งานจริง

ราคาเริ่มต้นไม่ทราบ แสดง null/unknown แอดมินตั้ง USDต่อล้านtoken โดยใช้อัตราสูงสุด input/output ของโมเดลที่ใช้อยู่ และวงเงินUSDย้อนหลัง24ชั่วโมง (0=ไม่ตั้งวงเงิน) จอง token/เงินแบบ transaction ก่อนทุกคำขอ รวม planner และคำตอบสุดท้าย งานล้มเหลว/ยกเลิกยังถือวงเงินที่จองไว้ตามแนวอนุรักษ์

ยอดเป็นประมาณการจากราคาที่ตั้งเอง ไม่ใช่ invoice หรือการตรวจราคาผู้ให้บริการอัตโนมัติ งานก่อนตั้งราคามีสถานะ unpriced และไม่ทราบยอด การเปลี่ยนราคาไม่มีผลย้อนหลังกับการจองเดิม เครื่องมือ keyless นับcallsแยก ไม่อ้างว่าค่าโฮสต์หรือค่าใช้จ่ายนอกระบบเป็นศูนย์

สถานะแยก last actual tool result + เวลา กับ MCP discoveryทุก5นาที กดตรวจการเชื่อมต่อได้โดยไม่เรียกAI/อ่านเว็บ การเชื่อมต่อสำเร็จไม่รับรองว่าทุกเว็บ/คลิปอ่านได้ โมเดลแสดงผลคำขอล่าสุด ไม่ยิง paid probe อัตโนมัติ

## หยุดและลบ

`/stop whole_server:false` หยุดห้อง หรือ trueทั้งเซิร์ฟเวอร์ /panelมีปุ่มเดียวกัน ระบายคิวที่ตรงขอบเขต ยกเลิกงานที่กำลังทำ ตรวจสถานะก่อนทุกส่วนที่ส่ง และไม่เล่นงานเก่าซ้ำตอนเปิดกลับ งานที่ส่งถึงผู้ให้บริการแล้วอาจเสียเงิน/ยังประมวลผลฝั่งนั้นอยู่ เปิดกลับผ่าน /panelหรือ /pause paused:false

พูด “อย่าจำฉัน” กับบอท หรือ /privacy store_data:false ปิดเก็บใหม่ ลบความจำ ประวัติที่บอทเก็บและ RAM ยังเรียกถามได้และข้อความคำถามยังต้องส่งให้AIเพื่อการตอบครั้งนั้น “ลบข้อมูลฉัน” ให้เปิดหน้าควบคุมยืนยัน DELETE; /memory clear confirm:true ใช้งานได้เหมือนเดิม ไม่ลบข้อความต้นฉบับใน Discord

`privacy-ledger.sqlite3` อยู่ข้างฐานข้อมูลจริง สิทธิ์0600 แยกจาก rotating backups เก็บเฉพาะตัวระบุ/เวลาลบ/optout/รหัสรายการ ไม่เก็บเนื้อหา ต้องรักษาไฟล์นี้ควบคู่ข้อมูลกู้คืนอย่างปลอดภัย ห้ามลบโดยคิดว่าเป็น cache มิฉะนั้นป้องกันการคืนข้อมูลจาก backupเก่าไม่ได้ คำสั่ง restore ใช้ ledgerปัจจุบันและคัดลอกเมื่อกู้ลงโฟลเดอร์ใหม่ ใช้ `--privacy-folder` ชี้โฟลเดอร์ledgerที่เก็บไว้ได้ ไม่ใช้ ledgerย้อนหลังแทนไฟล์ล่าสุด

ทดลองกู้คืนอัตโนมัติสัปดาห์ละครั้งหลังมีbackup และกดทดสอบทันทีในหน้าสถานะได้ ใช้โฟลเดอร์ชั่วคราว ตรวจ schema/integrity/readและกฎลบ แล้วลบพื้นที่ทดสอบ ไม่แทนฐานจริง ไม่ตรวจความถูกต้องเชิงความหมายของแชททุกข้อความ

## ขอบเขตและย้อนกลับ

ยังสี่Docker servicesเดิม ไม่มี GUI/host ports/dependenciesใหม่ ไม่มีอ่านรูป มีมผ่านภาพ หรือ voice เว็บ/ซับ/ประวัติ/มุกยังเป็นข้อมูลอ้างอิงที่ไม่น่าเชื่อถือ ไม่มีสิทธิ์เปลี่ยนค่า/เรียกเครื่องมือเอง

ก่อนเปิดใช้ให้สำรองฐานจริง เก็บ image before-controls-019f6c4 ทดสอบDocker/HTTP/recoveryและตรวจคำสั่งหลังเปิด รุ่นฐานข้อมูลยัง2 เพิ่มcolumnsที่เข้ากันได้ รุ่นเก่าอ่านได้แต่ไม่รู้จักledger/นโยบายใหม่ การย้อนกลับต้องรักษาledgerและใช้ขั้นตอนกู้คืนรุ่นใหม่นำกฎลบไปใช้ก่อน ไม่รับรองว่ารุ่นเก่าจะบังคับสิทธิ์เครื่องมือ/งบ/คำขอลบใหม่ได้
