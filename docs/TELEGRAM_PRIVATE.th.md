# Telegram แชตส่วนตัวบน OpenStick

ตัวเชื่อม Telegram เป็นงานภายในโปรเซสบอทเดิม ใช้ long polling ออกไปยัง Telegram และใช้ TokenMe เมื่อกำหนดคีย์ โดยมี Groq สำรอง และใช้บริการค้นหาเดิม จึงมีโควตา AI และเว็บร่วมกับ Discord ไม่เปิดพอร์ตเพิ่ม ไม่ต้องใช้ Docker เริ่มทำงานพร้อมบอทเมื่อกำหนดทั้ง token และ ID ที่อนุญาต

1. สร้างบอทผ่าน Telegram @BotFather แล้วเก็บ Bot Token เป็นความลับ
2. เปิดแชตส่วนตัวกับบอทนั้นและส่ง `/start` จากบัญชีที่จะอนุญาต
3. จากเครื่องที่เชื่อมต่อบอร์ดได้ ให้รัน `ssh -t user@<BOARD_IP> sudo python3 /opt/discord-companion-usb/scripts/setup_telegram.py` แล้วกรอก token ในช่องที่ไม่แสดงตัวอักษร เลือก ID ของตนจากรายการ `/start` ระบบจะบันทึกค่าในไฟล์ env ที่ root อ่านได้และรีสตาร์ตบริการ
4. ส่งข้อความทดสอบ รวมทั้งคำค้นสาธารณะและลิงก์ HTTPS สาธารณะหนึ่งลิงก์ `/clear` ลบบริบทชั่วคราวใน RAM

ใช้บอทใหม่ที่ไม่มี webhook และไม่มีตัว polling อื่นทำงานอยู่ ไม่ส่ง token ในแชตหรือ commit ลง Git ถ้า token รั่วให้เพิกถอนและสร้างใหม่ผ่าน BotFather จากนั้นตั้งค่าใหม่ สคริปต์จะแทนที่รายการ ID เดิมด้วย ID ที่เลือกหนึ่งบัญชี

อนุญาตเฉพาะ ID ใน `TELEGRAM_ALLOWED_USER_IDS` และเฉพาะแชตส่วนตัว ข้อความในกลุ่มและบัญชีอื่นจะถูกข้าม บริบท Telegram แยกจากประวัติ Discord โดยประวัติที่เปิดเก็บไว้มีอายุไม่เกิน 7 วันตามรายละเอียดด้านล่าง คำค้นที่อาจมีข้อมูลส่วนตัวจะขอให้เขียนใหม่ ลิงก์ที่ต้องล็อกอินหรือเว็บที่ต้องรัน JavaScript อาจอ่านไม่ได้ ข้อมูลใน URL และคำค้นที่ส่งไปค้นจะถูกส่งไปยังผู้ให้บริการเว็บภายนอก

## คำสั่งเพิ่มเติม

- `/status` ดู CPU, RAM, swap, พื้นที่ดิสก์, อุณหภูมิ และเวลาเปิดเครื่อง ใช้ได้จากแชตส่วนตัวทั่วไป ไม่ต้องอยู่ใน allowlist; จำกัดความถี่รวมเพื่อป้องกันการร้องขอถี่
- `/tone 0` ถึง `/tone 5` ตั้งโทนสำหรับผู้ใช้ที่อนุญาต ค่า 0 สุภาพ 4 เรื้อน และ 5 ซึน เมื่อพิมพ์ “หยุดแซว” ขณะใช้โหมด 5 จะเปลี่ยนเป็นโหมด 0
- `/remember ข้อความ`, `/memory`, `/forget หมายเลข` จัดการความจำระยะยาวเฉพาะผู้ใช้ Telegram ความจำที่ลบจะบันทึกใน privacy ledger เพื่อป้องกันการคืนจาก backup เมื่อใช้วิธีกู้คืนที่รองรับ; `/clear` ลบประวัติสนทนา Telegram และบริบทชั่วคราว พร้อมบันทึกการลบไว้ใน privacy ledger เพื่อป้องกันการคืนข้อมูลจาก backup
- ส่งรูป JPEG แบบภาพใน Telegram ครั้งละหนึ่งรูป ไม่เกิน 1 MiB พร้อมคำถามในคำบรรยาย หรือส่งรูปเปล่าเพื่อให้บอทอธิบาย ภาพถูกส่งไป Groq, นับโควตารูปโดยสำรอง 2,048 โทเคน และไม่บันทึกรูปลงดิสก์ หากรูปเกินขนาดให้ลดขนาดก่อนส่ง

## ดูความสามารถ

ส่ง `/help`, `/features` หรือถาม “ทำอะไรได้บ้าง” เพื่อดูฟีเจอร์ที่ตั้งค่าไว้ บอทจะแยกสถานะค้นเว็บ สิทธิ์เก็บข้อมูล การรองรับภาพ และสถานะตัวตั้งเวลาตามที่ตรวจได้จริง การเปิดใช้เครื่องมือไม่ได้รับประกันว่าเครือข่ายหรือโควตาพร้อมเสมอ คำสั่งที่เปลี่ยนข้อมูลต้องรอข้อความยืนยันจากบอท

- `/progress on` หรือ `/progress off` เปิดหรือปิดข้อความแจ้งเริ่มค้น/อ่านเว็บสำหรับบัญชีของคุณ ค่าเริ่มต้นเปิดอยู่ ข้อผิดพลาดและคำตอบยังแสดงตามปกติ

- ประวัติสนทนาที่เปิดเก็บจะอยู่ไม่เกิน 7 วันสำหรับการอ่าน และลบหมดอายุระหว่างงานดูแลรายชั่วโมง (backup เก่าอาจยังมีข้อมูลจนหมดอายุการเก็บ backup) เก็บสูงสุด 100 ช่วงต่อบัญชี; คุยปกติใช้ล่าสุดสูงสุด 6 ช่วง และ `/summary` สรุปจากข้อมูลล่าสุดตามขนาดที่จำกัด สรุปวันนี้ด้วย “สรุปแชทวันนี้” แยกตามบัญชี; ภาพไม่ถูกบันทึกลงดิสก์

## ข้อความเสียง

ส่งข้อความเสียง Telegram ไม่เกิน 2 นาทีและ 2 MiB บอทจะส่งเสียงไปถอดข้อความที่ Groq ด้วย `whisper-large-v3-turbo` และตอบเป็นข้อความ เสียงอยู่ในหน่วยความจำระหว่างทำงานเท่านั้น ไม่บันทึกไฟล์เสียง ถ้าตั้งให้เก็บข้อมูล ข้อความถอดเสียงและคำตอบจะใช้ประวัติ 7 วันและกฎ backup ตามข้างต้น

ใช้ `/transcript on` หรือ `/transcript off` เลือกแสดงข้อความถอดเสียง ค่าเริ่มต้นเปิด หากเป็นคำสั่งที่อาจเปลี่ยนข้อมูล บอทจะแสดงข้อความเพื่อยืนยันเสมอแม้ปิดการแสดงทั่วไป และต้องส่ง `/confirmvoice` ภายใน 2 นาทีจึงดำเนินการ จำกัดคำขอถอดเสียง 20 ครั้งต่อผู้ใช้ต่อชั่วโมงในหน่วยความจำ ตัวนับเริ่มใหม่เมื่อบอทเริ่มใหม่และผู้ให้บริการมีโควตาของตนเอง
