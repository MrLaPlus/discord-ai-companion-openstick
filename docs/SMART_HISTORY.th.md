# ถามแล้วค้นประวัติให้เอง

บอทอ่านประวัติที่ยังอยู่ใน Discord ได้ รวมถึงข้อความก่อนถูกเชิญเข้าเซิร์ฟเวอร์ โดยต้องมี View Channel และ Read Message History และห้องนั้นต้องถูกเปิด readable ไว้

## วิธีใช้

ในห้องบอท พิมพ์คำถามตามปกติ เช่น:

```text
ก่อนบอทเข้าห้องนี้ เคยคุยเรื่องอะไรกัน
เมื่อวานคุยเรื่องเกมอะไร
วันที่2025-05-01มีเรื่องอะไร
ปี 2568 เคยพูดถึงเกมแมวไหม
ข้อความแรกสุดในห้องนี้พูดว่าอะไร
```

บอทดึงประวัติเมื่อรับคำถาม ไม่ต้องใช้ `/history import` ก่อน หากถามข้ามห้อง ให้ mention ห้องจริงด้วย `#ชื่อห้อง` ใน Discord หรือเขียน “ห้องพิมพ์คุย” ให้ตรงชื่อ

## ข้ามห้องจำกัดสิทธิ์

```text
/ask question:ก่อนบอทเข้า ห้อง #พิมพ์คุย เคยคุยอะไรกัน
/ask question:เมื่อคืนห้อง #พิมพ์คุย คุยเรื่องเกมอะไร
```

`/ask` ตอบแบบส่วนตัว เฉพาะคนที่ใช้คำสั่ง ผู้ถามและบอทต้องอ่านห้องต้นทางได้ ห้องต้องเปิดอ่านและอยู่ share_group เดียวกับห้องที่ถาม ข้อมูล NSFW ไม่ไหลไปห้องทั่วไปแม้ตอบแบบส่วนตัว

ข้อความแชทปกติแชร์บริบทข้ามห้องได้เมื่อระบบพิสูจน์จาก role และ member overwrites ว่าทุกคนที่เห็นคำตอบสามารถอ่านประวัติต้นทางได้ ไม่ได้ตัดสินจากสิทธิ์แอดมินของผู้ถามเพียงคนเดียว หากขอบเขตคนอ่านไม่ตรงกัน ให้ใช้ `/ask` เพื่อดูคำตอบส่วนตัว

ตั้งกลุ่มแชร์ผ่าน `/settings channel` โดยระบุค่าห้องอื่นให้ครบตามคู่มือหลัก

## ที่มาของคำตอบ

ค่าเริ่มต้นบอทไม่แปะชื่อห้อง ผู้พูด ป้าย `[S1]` หรือลิงก์อ้างอิงให้ข้อความยาว หากคำถามต้องการชื่อคน/ห้องโดยตรง บอทยังตอบเนื้อหาที่ถามได้ตามบริบท

ถามกลับว่า **“เอามาจากไหน”** หรือ reply ข้อความบอทด้วย **“ขอแหล่งอ้างอิงหน่อย”** เพื่อดูแหล่งที่ใช้เป็นบริบท `/ask question:เอามาจากไหน` ใช้ขอที่มาของคำตอบส่วนตัวก่อนหน้าได้

บอทเก็บเฉพาะรหัสคำตอบกับรหัสแชทต้นทาง ไม่เก็บเนื้อหาคำตอบที่ AI สร้าง การดูที่มาตรวจสิทธิ์ใหม่ทุกครั้ง ถ้าต้นทางถูกลบ/แก้/หมดอายุ/เจ้าของ opt-out ลิงก์ที่อาศัยข้อมูลนั้นจะใช้ไม่ได้อีก คำตอบที่มาจากความรู้ทั่วไปหรือความจำที่สั่งจำอาจไม่มีแชทต้นทางให้อ้าง

## คำตอบยาว

แบ่งส่งต่อกันครั้งละไม่เกิน 1,900 UTF-16 units เพื่อเผื่อข้อจำกัด Discord อีโมจิอาจนับสองหน่วย ไม่ตัดคำตอบทิ้งเพื่อให้เหลือข้อความเดียว แต่ความยาวที่โมเดลสร้างยังอยู่ภายใต้ MAX_OUTPUT_TOKENS และโควตาที่ตั้งไว้

## ขอบเขตและการปรับแต่ง

- AUTO_HISTORY_ENABLED=true เปิดการดึงประวัติเมื่อถาม
- AUTO_HISTORY_MESSAGES=300 ข้อความต่อห้องสำหรับคำถามประวัติ; คุยทั่วไปเติมบริบทล่าสุดสูงสุด 30 ข้อความต่อห้อง
- AUTO_HISTORY_CHANNELS=3 ห้องต่อคำถาม
- AUTO_HISTORY_TOTAL=600 ข้อความรวมต่อคำถาม
- AUTO_HISTORY_TIMEOUT=20 วินาทีสำหรับขั้นดึงประวัติ
- AUTO_HISTORY_CACHE_SECONDS=60 เว้นการดึงช่วงเวลาเดิมซ้ำ
- HISTORY_RETENTION_DAYS=30 คืออายุแคชนับจากตอนดึง ไม่ใช่อายุข้อความต้นทาง จึงถามปีเก่าได้
- MAX_OUTPUT_TOKENS=768 เป็นค่าเริ่มต้นใหม่ ปรับเพิ่มได้ตามโควตา

รองรับ “ก่อนบอทเข้า”, “แรกสุด”, “เมื่อวาน”, “เมื่อคืน” (18:00 ของวันก่อนถึง 06:00), “วันนี้”, “เดือนที่แล้ว”, “ปีที่แล้ว”, วันที่ YYYY-MM-DD และปี ค.ศ./พ.ศ. ตามเขตเวลาที่ตั้งไว้

การค้นเป็นตัวอย่างในช่วงเวลาและจำนวนที่จำกัด ไม่ใช่ค้นทุกข้อความของเซิร์ฟเวอร์ในครั้งเดียว หากเรื่องเก่ามากให้ระบุวัน/ปี/ช่วงให้แคบลง ข้ามข้อความบอท เว็บฮุก และผู้ที่ปิดการเก็บข้อมูล ข้อความที่ถูกลบไปจาก Discord แล้วดึงกลับไม่ได้

ฐานข้อมูลอัปเกรดเป็น schema 2 เพื่อเก็บวันดึงและรหัสอ้างอิง ควร backup ก่อนอัปเดต หากย้อน image รุ่นเก่า ให้กู้ backup ก่อนอัปเกรดลงไฟล์ใหม่ตามคู่มือ ห้ามใช้ image เก่ากับฐานข้อมูล schema ใหม่
