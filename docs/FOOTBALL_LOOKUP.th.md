# ค้นตารางแข่งและสกอร์ฟุตบอล

เพิ่ม 2026-10-28 โดยใช้ MCP เดิม ไม่ต้องมีคีย์กีฬาเพิ่ม

ลองแท็กบอทแล้วถาม `แมนยูแข่งวันไหน`, `ตารางแข่งน่อล`, `โปรแกรมแมนซิตี้`, `ผลบอลลิเวอร์พูลล่าสุด` หรือระบุคู่แข่ง วันที่ และทีมชาย/หญิง/เยาวชนให้ชัด ใช้ `/ask` ได้ด้วย ต้องเปิดค้นเว็บและมีสิทธิ์เครื่องมือในห้องนั้น โหมดกดค้นจะยังขอให้ตรวจคำค้นก่อนส่ง

คำถามตารางแข่ง/ผล/คะแนนที่ระบุฟุตบอลหรือทีมที่รู้จักเข้าค้นเว็บได้โดยไม่ต้องมีคำว่า “ล่าสุด” ใช้ชื่อไทย/อังกฤษของ Manchester United, Manchester City, Arsenal และ Fleetwood Town เป็นตัวช่วยคำค้น ไม่สมมติว่าทีมอื่นคือแมนยู ชื่อทีมที่ยังไม่มี alias ค้นตามคำเดิมพร้อมคำว่าฟุตบอลได้

ให้ความสำคัญกับเว็บสโมสรที่ตรงกับชื่อทีม, Premier League, LiveScore, Flashscore และ Sofascore ในผลที่ค้นเจอ ใช้คำค้นเจาะโดเมนเมื่ออยู่ในขอบเขต 400 ตัวอักษร ไม่รับประกันว่าทุกแหล่งจะปรากฏหรือเปิดได้ อ่านเพียงหนึ่งหน้าจากผลที่เรียงแล้ว: รวมค้นและอ่านไม่เกิน 2 ครั้งต่อคำถาม ใช้ Playwright กับ PL/United/เว็บสกอร์ที่มักต้องใช้ JavaScript; City/Arsenal/Fleetwood ใช้ตัวอ่านข้อความก่อน เว็บอื่นหรือ URL โดยตรงยังใช้เส้นทางเดิม

แยกโปรแกรมยังไม่แข่ง กำลังแข่ง จบแล้ว เลื่อน หรือยกเลิก ระบุวัน คู่แข่ง รายการ และสกอร์เมื่อหลักฐานมีพอ เวลาแข่งแปลงตาม TIMEZONE (ค่าเริ่มต้น Asia/Bangkok) ได้เฉพาะเมื่อแหล่งระบุ timezone/UTC offset ชัด ถ้าไม่ชัดต้องแจ้งแทนการเดา รุ่นนี้เป็นการอ่านข้อมูลครั้งเดียว ไม่ได้สมัคร feed หรืออัปเดตทุกนาที

ผลจากการค้นถูกทำเครื่องหมายว่าเป็น snippet ไม่ใช่หน้าเต็มหรือผลสด หากอ่านหน้าไม่ได้จะเหลือเพียง snippet ให้ตอบอย่างจำกัด ไม่ใช้หน้าที่มีแค่เมนู/Loading/คำโฆษณามายืนยันสกอร์ ข้อมูลขัดกันหรือยืนยันล่าสุดไม่ได้ต้องบอกตรง ๆ ไม่ล็อกอิน ไม่ข้าม CAPTCHA ไม่เรียก API ลับ และไม่แต่งสกอร์

ไม่แนบที่มาทุกคำตอบตามค่าที่เลือกไว้ กดดูที่มาหรือถาม “เอามาจากไหน” เพื่อดู URL ที่ใช้ได้ โทนกวนทำงานตามระดับเดิม แต่ไม่ใช้มุกแทนสกอร์จริง ปุ่มใต้คำตอบยังมีสี่อันเดิม ไม่เพิ่มหน้าตั้งค่า/ปุ่มกีฬา
