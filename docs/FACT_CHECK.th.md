# ตรวจข่าวและข้อกล่าวอ้าง

Telegram หรือ Discord ใช้ “เช็กข่าว” ตามด้วยข้อความสาธารณะ เช่น `เช็กข่าว โลกโคจรรอบดวงอาทิตย์` หรือใส่ URL สาธารณะหนึ่งลิงก์ บอทจะค้นแหล่งอื่นสูงสุด 3 โฮสต์และพยายามอ่านหน้าเว็บก่อนสรุป แสดงวันที่ตรวจ ประเภทหลักฐาน และลิงก์แหล่งที่พบ หากบอกเพียง “เช็กข่าวนี้” จะขอให้ส่งข้อกล่าวอ้างหรือลิงก์ ไม่ดึงบทสนทนาเก่าไปค้นโดยอัตโนมัติ

กรณีลิงก์ บอทอ่านบทความและให้โมเดลเลือกคำค้นสาธารณะสั้น ๆ จากเนื้อหาที่อ่านได้ จากนั้นไม่ใช้โฮสต์ต้นฉบับเป็นแหล่งตรวจซ้ำ เครือข่ายเดียวกันต่างโฮสต์หรือบทความที่คัดลอกกันยังอาจไม่เป็นอิสระจริง การตรวจเป็นเพียงการประเมินจากข้อความที่อ่านได้ ไม่รับประกันความถูกต้อง หากข้อมูลไม่พอหรือขัดแย้งต้องระบุให้ชัด

ใช้สิทธิ์ search และ fetch_content ที่มีอยู่ หากอ่านหน้าไม่ได้อาจใช้ snippet โดยระบุให้ชัด และหากไม่มีหลักฐานจะไม่สรุปว่าจริงหรือเท็จ Discord โหมดที่ต้องกดยืนยันคำค้นยังไม่รองรับตรวจข่าวอัตโนมัติ และจะบอกข้อจำกัดนี้ก่อนส่งข้อมูล ไม่มีการตรวจจากประวัติห้องหรือข้อความของผู้อื่นโดยอัตโนมัติ
